Crypto Basics Hub Site Plan

Site Name

Crypto Basics Hub

This name was chosen because it clearly communicates that the site is a central, beginner-focused place to learn the fundamentals of cryptocurrency without jargon.

Optional domain: cryptobasicshub.org

Site Purpose

Crypto Basics Hub helps beginners make safer cryptocurrency decisions by providing clear educational guides, practical security tips, and simple tools for comparing coins and tracking personal readiness.

Scenarios

  • How do I store cryptocurrency safely if I am just getting started?
  • What warning signs should I look for before investing in a new coin?
  • Where can I contact the site owner to ask a beginner question?

Color Schema

The site uses a calm and trustworthy color palette that supports readability and a technical theme.

Deep Navy (#0f1f2c)

Used for headings, body text, and key UI text.

Signal Teal (#16506a)

Used for section accents, highlighted labels, and links.

Alert Gold (#d98f00)

Used for callouts, buttons, and emphasis.

Typography

  • Space Grotesk: Main headings and section titles.
  • DM Sans: Body text, lists, and supporting details.

These fonts are modern, readable, and help communicate a clear educational style.
